# Fund Subscription and Redemption Prediction Application
A Python/Tkinter desktop application developed as a team project to explore machine learning approaches for fund subscription and redemption prediction and liquidity risk assessment.

## Project Overview
Fund subscriptions and redemptions influence cash flows and liquidity planning. This project explored predictive approaches using multilayer perceptron (MLP) and logistic regression models, alongside a desktop interface for interacting with the prediction workflow.

The original application was developed collaboratively. The version presented here includes subsequent debugging and data pipeline improvements that I implemented independently.
